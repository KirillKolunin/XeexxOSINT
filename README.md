XeexxOSINT = The complete legitimate OSINT-Tool and have 2 versions - in terminal, and in GUI.

*How to Install?*

 On Windows.
 
 - Download Python 3.8+ and pip command with PATH.   

 - Download GIT on offical site.

 - Go command: https://github.com/KirillKolunin/XeexxOSINT.git

 - Download modules:

pip install requests

pip install phonenumbers

pip install tkinter

pip install dnspython

pip install python-whois

GUI Requires:

python -c "import whois; print(whois.__file__); print(hasattr(whois, 'whois'))"

- PhoneLookup.py

Files Have a GUI:

- Whois Lookup By Xeexx.py

- XOF 1.2.py
